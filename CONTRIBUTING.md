# Contributing

Thanks for taking the time to improve this experiment. Contributions can begin with a product observation, a rough interaction idea, or a focused code change.

## Share an idea

Open an issue and describe what you noticed. Include enough context for someone else to understand the situation: where it happened, what you expected, and why the change would help. Screenshots are useful when they do not contain private information.

Keep proposals narrow enough to discuss. One clear problem per issue makes it easier for other people to add evidence or suggest a different approach.

## Send a code change

1. Fork the repository and create a branch from `main`.
2. Install dependencies with `npm install`.
3. Make the smallest change that addresses the issue.
4. Run `npm run lint` and `npm run build`.
5. Open a pull request using the provided template.

Please keep sample names, links, conversations, and file paths fictional. Do not add screenshots, logs, access tokens, or other material that could identify a person without their permission.

## Scope

This repository explores how community feedback could be collected and presented. It does not reproduce Grok services or connect to private systems. Changes should support that purpose and preserve the independent-project disclaimer in the README.
